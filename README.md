# 💰 Smart Expense Tracker with Analytics Dashboard

A simple Python-based expense tracker that helps users record, manage, and analyze their daily expenses.

The application stores expenses in a SQLite database and provides an analytics dashboard using Streamlit. It shows spending summaries, category-wise spending, monthly spending, and unusual expenses.

## 🚀 Features

- ➕ Add daily expenses
- 📅 Select expense date
- 🏷️ Categorize expenses
- 📝 Add notes for expenses
- 💾 Store expenses using SQLite
- 📊 View total, average, and biggest expense
- 📈 Analyze spending by category
- 📅 Analyze monthly spending
- ⚠️ Detect unusual expenses
- 📋 View all recorded expenses
- 🛡️ Handle invalid inputs using exception handling
- 📝 Maintain application logs

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite3
- Pandas
- Statistics
- Git & GitHub
